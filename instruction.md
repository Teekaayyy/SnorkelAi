We have a nonlinear cart-pole control system at /service/app that combines a physics simulation, an Extended Kalman Filter state estimator, and a sampling-based adaptive Model Predictive Controller. Something has gone wrong across several of the modules and the controller is no longer able to stabilise the pole.

Run the simulation by instantiating the ClosedLoopSimulation class from /service/app/utils/simulation.py with the default ChallengeConfig and fix all the broken logic so the controller keeps the pole upright correctly. When working correctly, the simulation should run for the full 10-second duration without triggering an emergency stop, keep the pole angle well below 0.25 radians throughout, and produce health scores that remain non-negative at all times. Each module has inline docstrings describing what it is supposed to compute — use those as your guide when deciding what the correct logic should be.
